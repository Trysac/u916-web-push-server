# Stack

- **Runtime**: Node.js 22+ and any WinterCG / WebCrypto-compatible runtime (`globalThis.crypto.subtle`, `fetch`).
- **Runtime Dependencies**: None.
- **Dev Dependencies**:
  - `typescript`, `vitest`, `@vitest/coverage-v8`, `@biomejs/biome` for typechecking, testing, and linting.
  - `playwright` (dev-only) for the CI browser end-to-end conformance test.
