# CLAUDE.md

Read [AGENTS.md](AGENTS.md) first: it holds the commands, folder map, conventions and limits for this repository.

Essentials:

- Run `npm run check` before every commit; all gates must pass.
- Never edit `.github/`, `fabrica.json`, `docs-manifest.json` or `scripts/`.
- Never push to `main`; open a pull request.
- Keep secrets out of the repository, logs and prompts.
